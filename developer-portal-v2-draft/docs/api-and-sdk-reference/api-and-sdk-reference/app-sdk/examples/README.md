# Tutorials and examples

Start with [Build your first Control App](../getting-started.md) for a complete hosted run. Then use these tutorials to understand and adapt the code.

| Tutorial | You will learn | Prerequisites |
| --- | --- | --- |
| [Lower-third Control App](../lower-third-app.md) | Object lookup, configuration checks, existing payloads, draft/apply behavior, animations | `Default` output and the prepared lower-third composition |
| [Subcomposition selection and native fill-in form](../subcomposition-fill-in-form.md) | Target selection, native forms, draft lifecycle, stale callbacks, cleanup | Assigned composition with editable root/child controls |

Each tutorial includes focused snippets, code placement, checkpoints, and the complete hosted HTML. Snippets explain parts of the complete file; they are not standalone applications. Both ZIP downloads contain the same complete source shown on their pages.

For extensions, see [shared data and events](../shared-data-and-events.md), [local development](../hosted-and-local-development.md), and [composition import and output assignment](../reference/application.md#import-and-remove).
