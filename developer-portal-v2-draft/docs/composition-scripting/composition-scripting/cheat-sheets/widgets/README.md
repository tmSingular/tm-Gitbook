## Coverage boundary

This index covers the 26 widget types with dedicated installed scripting references used for this draft. It is not yet a complete current-catalog audit. **Whirligig** remains an explicit gap: its type/version, property contract, message names, and activation need verification before code is published.

Use [transforms](../transforms-and-visibility.md), [effects](../effects.md), [HTML text](../html-text.md), and the [message index](../widget-messages.md) for shared operations. Exact loaded schema and runtime behavior take precedence over a reference for a different version.
