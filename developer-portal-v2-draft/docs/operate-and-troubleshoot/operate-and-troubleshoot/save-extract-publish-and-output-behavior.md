# Save, extract, publish, and output behavior

Composer content, script-editor preview, Control App content, and actual output are separate checkpoints. Verify the destination that matters to your integration.

1. Save the edited composition and scripts.
2. Check the resulting behavior in a Player.
3. Update a managed composition extract where the app workflow requires it.
4. Exercise the actual Control App and its output URL.
