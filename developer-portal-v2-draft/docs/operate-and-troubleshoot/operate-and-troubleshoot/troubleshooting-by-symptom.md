# Troubleshooting by symptom

| Symptom                                             | Start with                                                                                                                                                                               |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A REST request is rejected                          | [Errors](../../api-and-sdk-reference/api-and-sdk-reference/rest/errors.md) and [authorization](../../api-and-sdk-reference/api-and-sdk-reference/rest/authorization.md)                  |
| Output does not react to a script                   | [Debugging](../../composition-scripting/composition-scripting/debugging-verification-and-deployment/debugging.md)                                                                        |
| Initial output works but later input does not       | [Reactive controls](../../composition-scripting/composition-scripting/how-to-guides/react-to-control-node-changes.md)                                                                    |
| Feed data does not appear                           | [Subscription](../../api-and-sdk-reference/api-and-sdk-reference/data-streams/subscribe.md) and [lifecycle](../../api-and-sdk-reference/api-and-sdk-reference/data-streams/lifecycle.md) |
| Preview works but app output differs                | [Save, extract, publish, and output behavior](save-extract-publish-and-output-behavior.md)                                                                                               |
| Motion or playback is slow                          | [Performance diagnostics](performance-and-browser-diagnostics.md)                                                                                                                        |
| Widget content or geometry differs after an upgrade | [Widget compatibility](../../composition-scripting/composition-scripting/widget-payloads-and-version-compatibility.md)                                                                   |

When requesting help, include the tested host, reproduction steps, expected result, observed result, and relevant versions. Remove credentials and sensitive payloads.
