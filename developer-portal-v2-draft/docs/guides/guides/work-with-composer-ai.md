# Work with Composer AI

Composer AI supports assisted inspection, authoring, script editing, and Player verification when its tools are connected to the assistant.

1. Open Composer AI and use its setup flow for your assistant.
2. Authorize the intended composition through the supported pairing flow.
3. Inspect the current structure, Control Nodes, links, widget versions, and template requirements before changing them.
4. Apply a bounded change, save it, and verify the requested behavior in a Player.
5. Test actual Control App delivery separately where the task requires it.

Use the installed **composer-ai** skill for the current tool interface, pairing, work lifecycle, cancellation, and recovery instructions. Do not paste private app or stream credentials into scripts or documentation examples.
