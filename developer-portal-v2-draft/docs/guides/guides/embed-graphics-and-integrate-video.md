# Embed graphics and integrate video

Use the [Graphics SDK](../../api-and-sdk-reference/api-and-sdk-reference/graphics-sdk/) to embed and control a Player from a host web page. Use the [Overlay SDK](../../api-and-sdk-reference/api-and-sdk-reference/overlay-sdk.md) for video-player integration.

* [Load app output](https://developer.singular.live/software-development-kits/graphics-sdk/guides-and-examples/load-app-instance-output)
* [Load a composition by URL](https://developer.singular.live/software-development-kits/graphics-sdk/guides-and-examples/load-a-composition-with-its-url)
* [Overlay SDK examples](https://developer.singular.live/software-development-kits/overlay-sdk/use-case-examples)

Confirm which integration supports the controls and scripts your use case needs. Host SDK methods and in-script methods are distinct; see [Host boundaries](../../composition-scripting/composition-scripting/core-concepts/host-boundaries.md).
