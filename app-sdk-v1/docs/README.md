# Singular App SDK
updated: Oct.2026
by: tm

Welcome to the Singular.live App SDK documentation!

This guide provides all the resources needed to create, develop, and publish Singular native apps. The documentation covers installation, key functions, API references, and best practices to support developers of all levels.

## What can native Singular app can do

Singular apps offer a range of functionalities, including:

* Importing and removing compositions from app instances
* Reading, updating, and resetting control nodes
* Analyzing a composition's structure
* Triggering animations in sub-compositions
* Utilizing custom or pre-built Singular fill-in forms
* Accessing external data sources and services
* Using the storage object to save and synchronize content across multiple app instances that are opened simultaneously
