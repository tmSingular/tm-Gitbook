# Work with layout

Separate a tile's canvas bounds from widget-specific content properties. Use the widget's documented layout methods for position and size, and its payload schema for content.

Check the immediate parent, anchor, units, links, and native animation ownership before calculating a scripted position. Verify representative screen sizes and visible bounds in the Player.
