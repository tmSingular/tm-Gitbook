# Scope

Attach the script to the composition that owns the behavior. A root script coordinates broader composition behavior; a sub-composition script can keep local presentation logic close to its widgets.

Resolve the intended target before changing it. Search results are arrays, so handle an empty result and avoid assuming the first matching name always identifies the intended object.
