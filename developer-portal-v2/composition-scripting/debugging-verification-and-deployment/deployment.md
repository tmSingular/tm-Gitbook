# Deployment

Save and test each stage of the delivery path.

1. Save the composition scripts and the composition as required by the editor.
2. Verify initial output and subsequent updates in a Player.
3. Update the Control App's managed composition extract where required.
4. Test the intended app and its actual output URL.
5. Record the saved revision and the environments exercised.

Saving composition content and publishing an app are separate operations. Use the relevant product workflow for the destination you intend to update.
