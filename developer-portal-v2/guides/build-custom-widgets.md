# Build custom widgets

Use the Widget SDK when you need a reusable widget with its own UI definition and rendering behavior.

- [Prepare the development environment](https://developer.singular.live/software-development-kits/widget-sdk/preparing-your-environment)
- [Widget SDK getting started](https://developer.singular.live/software-development-kits/widget-sdk/getting-started)
- [UI definitions](https://developer.singular.live/software-development-kits/widget-sdk/reference/widget-ui-definition)
- [Lifecycle callbacks](https://developer.singular.live/software-development-kits/widget-sdk/reference/widget-callback-functions)
- [Widget SDK reference](../api-and-sdk-reference/widget-sdk.md)

For changing an existing widget at runtime, use [Set widget properties](../composition-scripting/how-to-guides/set-widget-properties.md) instead.
