# First REST integration

Use the [published REST quick start](https://developer.singular.live/quick-start) to read control data, identify a sub-composition, change its text, and trigger its animation state.

Keep the output URL open while sending requests. Use IDs returned for your own app, rather than copying sample IDs. Check the response and the visible output separately.
