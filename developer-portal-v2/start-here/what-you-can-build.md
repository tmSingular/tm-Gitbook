# What you can build

Use Singular to build lower thirds, score graphics, tickers, interactive overlays, and graphics that respond to live data.

| What you want to do | Continue with |
|---|---|
| Design a graphic and its animations | [Build and animate in Composer](../guides/build-and-animate-in-composer.md) |
| Update text or trigger In/Out from an application | [Control overlays through REST](../guides/control-overlays-through-rest.md) |
| Show frequently changing feed values | [Connect live data](../guides/connect-live-data.md) |
| Add formatting or event-driven behavior | [Composition scripting](../composition-scripting/README.md) |
| Embed output in a website or video workflow | [Embed graphics and integrate video](../guides/embed-graphics-and-integrate-video.md) |
| Create a reusable custom widget | [Build custom widgets](../guides/build-custom-widgets.md) |

Continue with [Choose an integration](choose-an-integration.md) to select the interface for your project.
