# First overlay

Follow the [published first-overlay walkthrough](https://developer.singular.live/quick-start) to create an app from a template, obtain its output URL, and view the graphic in a browser.

Before continuing, confirm that you can open the output URL and take the intended overlay In and Out from its Control App.

Next, choose [your first REST integration](first-rest-integration.md) to control that output remotely, or [your first composition script](first-composition-script.md) to add runtime behavior.
