### Introduction to the Dashboard

Below, you'll find descriptions of the six main areas of the Dashboard, including:

1. The [platform toolbar](dashboard-reference.md#1.-platform-toolbar)
2. The [main panel](dashboard-reference.md#2.-main-panel)
3. The [main panel filters](dashboard-reference.md#3.-main-panel-filters)
4. The [dashboard inspector](dashboard-reference.md#the-dashboard-inspector)
5. The [navigation panel](dashboard-reference.md#4.-navigation-panel)
6. The [new menu and templates](dashboard-reference.md#5.-new-menu-and-templates) buttons

#### 1. Platform toolbar

The platform toolbar provides access to your subscription status, Singular Support, and the user menu, which contains settings, the output manager, and the data stream manager.

<figure><img src="../../.gitbook/assets/Platform toolbar.png" alt=""><figcaption><p>Platform toolbar</p></figcaption></figure>

#### 2. Main panel

This is where you can view all of your assets. You can organize them into folders for easy access.

<figure><img src="../../.gitbook/assets/Main Panel.png" alt=""><figcaption><p>Main panel</p></figcaption></figure>

#### 3. Main panel filters

These filters allow you to search for and sort your assets within the main panel.

<figure><img src="../../.gitbook/assets/Main panel filters.png" alt=""><figcaption><p>Main panel filters</p></figcaption></figure>

#### 4. Dashboard inspector

The Dashboard inspector displays info about the assets in the main panel. It is useful for getting IDs and asset URLs, changing asset thumbnails, and viewing asset details like creation time, updated time, and more.

<figure><img src="../../.gitbook/assets/Dashboard inspector.png" alt=""><figcaption><p>Dashboard inspector</p></figcaption></figure>

#### 5. Navigation panel

This is where you can navigate through your Singular assets.

<figure><img src="../../.gitbook/assets/Navigation panel.png" alt=""><figcaption><p>Navigation panel</p></figcaption></figure>

#### 6. New menu and templates

The new menu is where you can create and upload a variety of assets. Templates contains overlay templates for live shows, including sports, news, education, and more. It also includes resources like composition scripts, compositions for learning advanced widgets, and more.

<figure><img src="../../.gitbook/assets/New menu and templates.png" alt=""><figcaption><p>New menu and templates</p></figcaption></figure>
