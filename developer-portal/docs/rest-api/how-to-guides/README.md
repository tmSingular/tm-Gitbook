# How-to guides

The how-to guides in this section describe most of the common tasks involved in updating and controlling overlays using the Singular REST API. In these guides, you'll learn how to get information about app instances and sub-compositions, as well as how to update overlay content and animate overlays In and Out. They include:

<table data-view="cards"><thead><tr><th></th></tr></thead><tbody><tr><td><a href="get-a-control-apps-api-token.md">How to get a control app's API token</a></td></tr><tr><td><a href="get-a-compositions-sub-composition-ids-and-names-and-their-payload-structures.md">How to get an overlay's sub-composition ID(s)</a></td></tr><tr><td><a href="get-a-control-apps-model.md">How to get a control app's model</a></td></tr><tr><td><a href="get-a-control-apps-metadata.md">How to get a control app's metadata</a></td></tr><tr><td><a href="update-a-sub-compositions-content.md">How to update an overlay's content</a></td></tr><tr><td><a href="update-a-sub-compositions-animation-state.md">How to animate overlays In and Out</a></td></tr><tr><td><a href="update-a-sub-compositions-content-and-animation-state-in-one-call.md">How to simultaneously update and overlay and animate it In and Out</a></td></tr><tr><td><a href="update-multiple-sub-compositions-in-one-call.md">How to update multiple sub-compositions in one request</a></td></tr></tbody></table>

These how-to guides are language and platform agnostic. Thus, you can follow along using cURL or whatever language you use to make API requests, as well as on Postman or the API platform of your choice.

For more basic instructions about getting started with Singular, check out the [quick start](../../quick-start.md). The knowledge you gain going through it will enable you to follow the how-to guides here.

{% hint style="info" %}
These how-to guides require a Singular account, which you can get [here](https://app.singular.live/users/login).
{% endhint %}
